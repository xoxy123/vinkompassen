# Vinkompassen

Sök Systembolagets sortiment efter smak, mat och butik.

Det här repot innehåller **enbart den byggda sidan** — en fristående
`index.html` utan externa beroenden. Källkoden ligger separat.

Öppna: https://xoxy123.github.io/vinkompassen/

Alkohol kan skada din hälsa. 20-årsgräns gäller för köp på Systembolaget.
Appen säljer ingenting och är inte kopplad till Systembolaget AB.
